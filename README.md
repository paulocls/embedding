I. Instruções para reprodução do ambiente.

Instalação e Configuração do Ollama

1.Acessar o site www.ollama.com
2.Clicar o arquivo ollama.exe
3. Volta ao site do ollama, clica em models e escolha o modelo de sua preferencia.
4. No terminal, digite ollama run <modelo>
5. Para verificar os modelos instalados, ollama list
6. Para usar o ollama, digite ollama run <modelo>. A partir do momento, você pode interagir com o Ollama.
